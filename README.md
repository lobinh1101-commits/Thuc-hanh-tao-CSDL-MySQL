# Thuc-hanh-tao-CSDL-MySQL
Schemas → Create Schema → nhập my_database_gui → Apply → Apply → Finish.
Schemas → Create Schema → nhập my_database_gui → Apply → Apply → Finish
1. Schemas: Mở MySQL Workbench, tìm mục SCHEMAS ở bên trái.
2. Create Schema: Nhấn chuột phải vào vùng SCHEMAS hoặc nhấn biểu tượng tạo Schema mới, chọn Create Schema.
3. Nhập my_database_gui: Nhập tên my_database_gui vào ô tên cơ sở dữ liệu.
4. Apply: Nhấn nút Apply.
5. Apply: Trong cửa sổ xác nhận câu lệnh SQL, nhấn Apply lần nữa.
6. Finish: Nhấn Finish để hoàn tất.
